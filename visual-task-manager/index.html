Frequently asked questions

How Bubbles fits your workflow

How does Bubbles show task urgency?

Tasks grow visually with time and priority, helping the items that need attention stand out.

Does Bubbles include a focus timer?

Yes. Bubbles includes a Pomodoro timer and supports Live Activities to keep the current focus session visible.

Can Bubbles handle repeating tasks?

Yes. You can build routines for repeatable work and follow streaks and statistics over time.
